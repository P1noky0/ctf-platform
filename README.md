# 🛡️ CTF Platform

A self-built Capture The Flag (CTF) platform created for learning
web development, cybersecurity, and software engineering.

> 🚧 This project is currently under development.

## 📌 About

This project aims to build a CTF platform from scratch while exploring
modern web development technologies and cybersecurity concepts.

The project will gradually evolve from a simple frontend application
into a full-stack CTF platform.

## 🎯 Goals

- Learn modern frontend development
- Learn backend development and API design
- Practice database design
- Implement user authentication
- Build and manage CTF challenges
- Explore cybersecurity concepts
- Practice secure web application development
- Learn software engineering and project management

## � Git Workflow

The usual workflow in VS Code is:

1. Edit your files.
2. Open the Source Control panel in the sidebar (or press Ctrl+Shift+G).
3. Check Git status to see which files changed.
4. Click the plus button next to files or run `git add .` to stage changes.
5. Commit with a message using `git commit -m "your message"`.
6. Push with `git push` to upload the changes to GitHub.

> Git status is not in the Edit menu. In VS Code, it appears in the Source Control view, where you can also stage, commit, and push changes.
